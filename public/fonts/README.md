# Fonts

Rumi uses **Google Fonts** (no local commercial files required):

| Role | Family | Source |
|---|---|---|
| Headings, nav, buttons, UI chrome, wordmark | **Inter** | `next/font/google` |
| Body paragraphs / reading text | **DM Sans** | `next/font/google` |

Wired in `src/app/fonts.ts` → CSS variables `--font-display` (Inter) and `--font-sans` (DM Sans).
